# 💀 SALO Platformer - Кладбищенские Приключения

Браузерная игра-платформер в стиле Super Mario без бекенда, созданная с использованием React и Phaser 3 с применением best practices.

## 🎮 Описание

Профессиональный платформер с пиксельной графикой, созданный с использованием современных технологий и best practices:

### ✨ Особенности:
- **Pixel Art графика** — качественные пиксельные спрайты с детализацией
- **Параллакс фоны** — многослойный фон с луной и звездами
- **Particle Systems** — эффекты разрушения, пыль при беге, салюты
- **Анимации** — плавные анимации персонажей и UI
- **Современный UI** — стильный интерфейс с прогресс-баром и анимациями
- **Scene Management** — разделение на сцены (Boot, Main)
- **React Integration** — чистая интеграция Phaser с React
- **🎮 Система никнеймов** — уникальные игровые имена для каждого игрока
- **🏆 Рейтинг игроков** — таблица лидеров с сохранением результатов
- **🔐 Аутентификация** — Email Magic Link, Google OAuth или анонимная игра

## Установка и запуск

### Требования
- Node.js 16+ и npm

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Игра откроется автоматически в браузере на `http://localhost:3000`

### Сборка для продакшена
```bash
npm run build
```

Собранные файлы будут в папке `dist`

### Просмотр продакшен сборки
```bash
npm run preview
```

## 🛠️ Технологии

- **React 18.2** — UI библиотека
- **Phaser 3.80.1** — игровой движок
- **Vite 5.0** — сборщик и dev-сервер
- **HTML5 Canvas** — рендеринг с pixelArt режимом
- **Arcade Physics Engine** — физика
- **Particle System** — эффекты частиц

## 🏗️ Архитектура (Best Practices)

### Scene Management
- **BootScene** — загрузка и генерация всех ассетов
- **MainScene** — основная игровая логика

### Pixel Art рендеринг
```javascript
{
  pixelArt: true,
  antialias: false,
  roundPixels: true
}
```

### Особенности реализации
- **React Hooks** — `useState`, `useEffect`, `useRef` для управления состоянием
- **Scene-based Architecture** — разделение игры на сцены
- **Particle Systems** — Phaser 3 particles для эффектов
- **Parallax Scrolling** — многослойные фоны с разной скоростью
- **Programmatic Sprites** — генерация пиксельных спрайтов через Canvas API
- **Tweens** — плавные анимации через Phaser Tween system
- **Camera System** — следование за игроком с deadzone

### Graphical Features
- 🌙 Луна с кратерами
- ⭐ Анимированные звезды
- 🌲 Силуэты деревьев на заднем плане
- 🌫️ Туман с градиентом
- ✨ Светлячки/частицы в воздухе
- 💥 Эффекты разрушения с screen shake
- 🎆 Фейерверки с вспышками

## 🎮 Система никнеймов и рейтинга

### Настройка Supabase

Для работы системы никнеймов и рейтинга необходимо настроить Supabase:

1. **Выполните SQL миграцию** — см. `NICKNAME_MIGRATION.md`
2. **Настройте переменные окружения** — `.env` файл
3. **Настройте OAuth** — Google Cloud Console

Подробная документация:
- 📖 `NICKNAME_FEATURE.md` — описание системы никнеймов
- 📖 `NICKNAME_MIGRATION.md` — SQL миграция для БД
- 📖 `SUPABASE_SETUP.md` — настройка Supabase
- 📖 `AUTH_METHODS.md` — методы аутентификации

### Особенности системы

- ✅ Уникальные игровые ники (3-20 символов, пробелы разрешены)
- ✅ Проверка на занятость ника в реальном времени
- ✅ Нельзя изменить после установки
- ✅ Отображение в таблице лидеров
- ✅ Email Magic Link + Google OAuth
- ✅ Анонимная игра без сохранения результатов
